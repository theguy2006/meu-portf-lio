# Portfólio — Cauã Franco

Projeto de portfólio pessoal feito com HTML, CSS e JavaScript puro.

## Como abrir
1. Extraia o arquivo ZIP.
2. Abra a pasta no VS Code.
3. Abra `index.html` no navegador ou use a extensão Live Server.

## Personalização obrigatória antes de publicar
- No `index.html`, procure `SEUEMAIL@EXEMPLO.COM` e substitua pelo seu e-mail.
- Atualize os links do GitHub e LinkedIn na seção de contato.
- Quando publicar seus projetos, acrescente links reais para demonstração e repositórios.
- Confira se as descrições e tecnologias listadas correspondem ao estado atual de cada projeto.

## Arquivos
- `index.html` — estrutura e conteúdo.
- `style.css` — identidade visual, layout e responsividade.
- `script.js` — menu mobile, ano automático, botão voltar ao topo e animações.

## Publicação gratuita
Você pode publicar pelo GitHub Pages:
1. Crie um repositório público no GitHub.
2. Envie os três arquivos para a raiz do repositório.
3. Abra Settings → Pages.
4. Em Build and deployment, escolha Deploy from a branch.
5. Selecione `main` e `/ (root)`, depois salve.

A fonte do Google Fonts depende de conexão com a internet. O site continua funcional sem ela, usando fontes alternativas.
